# 主菜单 UI 色彩令牌

> 适用范围：主菜单与设置 / 制作名单弹层。装配工作台沿用其自身配色，不在此规范内。
> 原则：**只有一个强调色**，且强调色只出现在「激活态、编号、重点线、状态点」四类位置，画面占比不超过 5%。

## 1. 色板

| 令牌 | 色号 | 用途 | 使用面积 |
| :--- | :--- | :--- | :--- |
| **Ink** | `#05080A` | 全屏底色（最暗层） | 主要背景 |
| **Graphite** | `#0A1014` | 弹层、浮起面、次级块面 | 小面积 |
| **Steel** | `#1A2429` | 1px 分割线、描边、未激活控件 | 线性元素 |
| **Platinum** | `#EEF2F3` | 标题、主文本 | 文字 |
| **Ash** | `#8B99A1` | 次要文本、英文副标、未选中菜单项 | 文字 |
| **Signal** | `#5BE3D0` | 唯一强调色：激活编号、重点线、状态点 | ≤ 5% |

### 透明度阶梯

| 场景 | 取值 |
| :--- | :--- |
| 分割线（常态 / 悬停） | `Steel 55%` / `Steel 80%` |
| 主文本（未选中 / 选中） | `Platinum 62%` / `Platinum 100%` |
| 英文副标（未选中 / 选中） | `Ash 28%` / `Ash 65%` |
| 编号（未选中 / 选中） | `Ash 55%` → `Signal 100%` |
| 线框主体（近 / 远） | `Signal 42%` / `Signal 18%` |

## 2. 对比度

| 组合 | 对比度 | 结论 |
| :--- | :--- | :--- |
| Platinum on Ink | ≈ 18.6 : 1 | 正文 AAA |
| Ash on Ink | ≈ 6.3 : 1 | 次要文本 AA |
| Signal on Ink | ≈ 12.2 : 1 | 强调可用 |

## 3. 字体

| 角色 | 字体 | 字重 | 字号 | 字距 |
| :--- | :--- | :--- | :--- | :--- |
| 主标题 | Bahnschrift | 300 (Light) | 76 | +0.5 |
| 菜单项 | Microsoft YaHei UI | 400 | 19 | +0.6 |
| 正文 | Microsoft YaHei UI | 400 | 16–18 | 0 |
| 编号 / 元信息 | Cascadia Mono | 400 | 9 | +1.2 ~ +3.2 |

## 4. 禁用做法

- 不使用渐变彩色文字、描边文字、外发光文字。
- 不使用第二个强调色（状态色只允许出现在工作台与诊断结果里）。
- 不使用满屏网格、扫描线、噪点闪烁、角标刻度等装饰层。
- 不为菜单项添加填充色块；激活态只用「文字提亮 + 1px 底线」表达。
